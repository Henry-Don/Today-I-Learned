# IBR and Grid Integration

这一层是仓库的核心深度之一，连接变流器控制、电力系统稳定性和 BESS 并网工程。

## Grid Following

- GFL 为何依赖 PLL
- SRF-PLL、PLL 带宽与弱电网交互
- dq 电流控制、P/Q 与 DC-link 外环
- 电流源外特性、限流和故障恢复

## Grid Forming

- 电压源外特性
- P-f 与 Q-V droop
- VSG、matching control 与 virtual oscillator 基础
- 虚拟惯量与虚拟阻抗
- 黑启动、孤岛运行和并联功率分配
- current limiting 与故障后控制恢复

## Stability and Interaction

- SCR、X/R 和系统强度
- 相位跳变、电压/频率扰动与 FRT
- GFL/GFM 混合运行与多机交互
- 正负序电流优先策略
- protection-quality fault current
- impedance-based stability
- frequency scanning
- 多厂商控制交互
