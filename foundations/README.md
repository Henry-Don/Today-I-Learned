# Foundations

这一层保存后续电力系统、变流器控制和模型验证都会反复使用的基础知识。目标不是无限扩展数学体系，而是能推导、实现并解释工程模型。

## Mathematics and Control Foundation

- 复数、相量与二维旋转
- 微分方程
- 线性代数、特征值与模态
- Laplace 与 Fourier 变换
- Bode 与 Nyquist 分析
- 状态空间、可控性与可观性
- 连续与离散控制
- PI/PID、饱和与 anti-windup
- 参数敏感度、优化基础、概率与时序数据

## Electrical Engineering Foundation

- 三相系统、RMS、瞬时值与标幺值
- 电路元件、正弦稳态、阻抗与复功率
- abc、αβ 与 dq 坐标的物理和数学关系
- 正序、负序与不平衡量
