# Tools

工具学习服务于“模型建立 → 工况执行 → 结果分析 → 模型验证 → 工程报告”的完整工作流。工具熟练度不能替代对物理、控制和模型边界的理解。

| 工具 | 定位 | 重点能力 |
| --- | --- | --- |
| MATLAB / Simulink / Simscape Electrical | 当前核心 | 参数化建模、GFL/GFM 控制、批量测试、结果判定 |
| Python + Git + SQL | 当前核心 | 科学计算、仿真编排、回归测试、版本与证据管理 |
| PSCAD / EMTDC | 下一阶段核心 | EMT、弱电网、故障、控制交互、Multiple Run 与自动化 |
| PSS®E | 下一阶段核心 | 潮流、短路、RMS 动态、大系统研究与 Python API |
| DIgSILENT PowerFactory | 熟练级次核心 | 潮流、短路、RMS 动态、保护与商业工程场景 |
| RTDS / OPAL-RT / Typhoon HIL / Speedgoat | UNSW 阶段重点 | CHIL、PHIL 与实时模型验证 |
| LabWindows/CVI / TestStand / SPEA | 工业测试底座 | 测试序列、日志、追溯、覆盖率与部署 |

辅助工具包括 LTspice、Excel/Power Query、Power BI、draw.io/Visio 及基础 CAD/EPLAN。只有在形成实际学习笔记时才为单个工具新增目录。
