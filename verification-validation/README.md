# Verification and Validation

验证、自动化与模型可信度是本仓库的核心差异化能力。这一层关注如何证明模型、控制和工程结果满足需求，而不只是让仿真成功运行。

## Test Engineering

- V 模型
- verification 与 validation 的区别
- requirements traceability
- test coverage 与 boundary testing
- regression testing 与 fault injection
- 自动判定、失败重试和 audit trail

## Model Validation

- RMS 与 EMT 模型边界
- PSCAD 与 PSS®E 的通道映射、时间对齐和误差指标
- 模型、参数、工况与结果的版本管理
- model configuration management
- 现场数据与模型结果对比

## HIL and Diagnosis

- MIL、SIL、CHIL 与 PHIL
- time synchronisation 与 alarm correlation
- root cause analysis、FMEA 与 RAMS 基础
- 日志、错误码、异常分类和重复事件识别

## Data and Security

- remote access、cybersecurity 与 data segregation
- 权限、日志和证据链
- 对自动化工具输出保持人工工程判断和责任边界
