# Power Systems

这一层建立电网分析的核心底座，重点是理解模型假设、结果可信度及何时需要升级分析方法。

## Study Scope

- 标幺值与系统基准
- 变压器、线路、负荷和电源模型
- 潮流、无功限值与收敛
- 短路、电网故障与故障电流
- 对称分量和不平衡系统
- P-f 与 Q-V 关系
- 电压、频率、暂态和小扰动稳定性
- 振荡模态、阻尼与特征值
- 系统强度、SCR 类指标与网络阻抗
- 谐波、谐振与电能质量
- 继电保护与保护配合
- 经济调度与最优潮流基础

## Boundary

电力系统原理放在这里；GFL/GFM、PLL、弱电网控制交互和阻抗稳定性放在 [IBR and Grid Integration](../ibr-grid-integration/README.md)；具体澳洲规则放在 [Australia Grid Connection](../australia-grid-connection/README.md)。
