## Minimum Output for a Deep Read

- 写清论文或文件解决的问题
- 手推核心方程并记录符号约定
- 复现至少一张关键图或结果
- 改变一个条件，检查结论是否仍成立
- 比较文献模型与当前工程模型的差异
- 记录可进入项目报告的结论、限制和证据
